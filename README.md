# OLA Data Analysis Project

## 📊 Overview
This project analyzes OLA ride booking data (20K+ records) to extract insights on ride trends, revenue, cancellations, and customer behavior.

## 🛠 Tools Used
- Power BI
- Python (Pandas, NumPy)
- SQL (conceptually used)
- Excel

## 📌 Key Features
- 5-page interactive dashboard
- Ride volume and booking status analysis
- Revenue analysis (6.9M+)
- Cancellation analysis (~28%)
- Customer and driver ratings

## 📈 Insights
- High cancellation rate impacts ride completion
- Cash and UPI are dominant payment methods
- Vehicle performance varies based on ride distance

## 📂 Project Structure
- dataset/ → Contains dataset (Bookings.csv)
- dashboard/ → Contains Power BI (.pbix file)

## ⚠️ Note
SQL queries and transformations are implemented within the Power BI dashboard.
